## How this was measured

1. `npm pack @cortexkit/opencode-magic-context@0.49.41`, `…@0.49.42`, `…@0.49.43` into
   `/tmp/opencode/mc-review/`, extracted each, and compared `src/` trees.
2. Recomputed `sha256sum` of the seven files per version.
3. Added both releases to `patches/` from those digests, then let `MatcherRules.test.ts` derive each
   release from the fixtures with the same `locate`/`applyReplacements` the stager uses: it passed for
   both versions, which is the assertion that the fixtures, the recorded `before`/`after` and the
   replacement counts agree.
4. `tests/fixtures/magic-context-0.49.42/` and `…-0.49.43/` hold those seven files, a reduced
   `package.json` and a `NOTICE.md` naming the tarball and every checksum, as for every earlier release.
