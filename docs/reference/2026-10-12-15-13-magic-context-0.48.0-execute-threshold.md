read from the published package on 2026-10-12. The 0.47.0 evidence and its reasoning are in
`2026-10-11-19-37-magic-context-0.47.0-execute-threshold.md`; this document only records what 0.48.0
shows. 0.48.0 is not installed on this machine; the patch is ready for when it is.

## 2. The schema still rejects values below 20

`package/src/config/schema/magic-context.ts` lines 1237–1242 are the 0.47.0 schema unchanged:
`z.number().min(20).max(90, EXECUTE_THRESHOLD_CAP_MESSAGE)` for a plain number, the `default` key
and the per-model catch-all. Compiled in `dist/v2/server-zm570tr2.js` lines 5614–5615:

```js
execute_threshold_percentage: union([
  number2().min(20).max(90, EXECUTE_THRESHOLD_CAP_MESSAGE),
  object({ default: number2().min(20).max(90, EXECUTE_THRESHOLD_CAP_MESSAGE) }).catchall(number2().min(20).max(90, EXECUTE_THRESHOLD_CAP_MESSAGE))
```

## 3. The code that uses the threshold still has no lower bound

`dist/v2/context-sf98kstd.js` (the OpenCode 2 runtime):

- `resolveExecuteThresholdDetail` (line 1779): its 41 lines differ from 0.47.0's only in two renamed
  log helpers (`sessionLog2`, `log2`). It replaces the value only when it is not finite or negative
  (line 1837) and caps it at the top (line 1840, `Math.min(resolved, MAX_EXECUTE_THRESHOLD)`,
  `MAX_EXECUTE_THRESHOLD = 90` in `dist/v2/server-k8x2rbxc.js` line 1357).
- The proactive historian trigger (line 6027) is `Math.max(0, executeThresholdPercentage -
  PROACTIVE_TRIGGER_OFFSET_PERCENTAGE)` with `PROACTIVE_TRIGGER_OFFSET_PERCENTAGE = 2` (line 5971):
  13 still gives 11.
- Wrapup sizing (`dist/v2/server-k8x2rbxc.js` lines 17922, 17944, 18899) multiplies the context limit
  by the percentage with `Math.max(1, …)`.

So the same three replacements make a configured 13 work as 13 on 0.48.0. The e2e test
`tests/e2e/lifecycle.test.ts` applies and undoes the patch on the fixture files and checks both
checksums. After updating to 0.48.0: `opencode-magic-context-patches apply`, restart OpenCode, then
`opencode-magic-context-patches effect` (expects `respected`).
