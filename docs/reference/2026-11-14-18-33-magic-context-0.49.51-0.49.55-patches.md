## Cause

0.49.53 wrapped the pass-permission callback:

```js
afterCapture(sessionId, "pass permission report", () => deps.onPassPermission?.(sessionId, postTransformResult.prefixMutationPermitted));
```

so the text the old anchor looked for is now followed by `));`, and the anchor lost its trailing `;`.
On `tests/fixtures/magic-context-0.49.55/dist/index-9n6mdfqy.js` the counts are: with `;` 0
occurrences, without `;` 1 occurrence. The anchor's start sits 527 characters before the hit
(`lastIndexOf` returns 1188765; the hit is at 1189292).
