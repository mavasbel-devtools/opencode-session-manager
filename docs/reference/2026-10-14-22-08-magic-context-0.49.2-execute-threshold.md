read from the published package on 2026-10-14. The 0.47.0 reasoning is in
`2026-10-11-19-37-magic-context-0.47.0-execute-threshold.md`, the later checks in
`2026-10-12-15-13-magic-context-0.48.0-execute-threshold.md` and
`2026-10-12-23-15-magic-context-0.49.0-execute-threshold.md`; this document only records what 0.49.2
shows, compared with the published 0.49.0 package. 0.49.1 (published 2026-10-14T18:27:16.299Z) was
never installed here and is not added.

## 2. The schema still rejects values below 20

In `package/src/config/schema/magic-context.ts` the three `z.number().min(20).max(90,
EXECUTE_THRESHOLD_CAP_MESSAGE)` calls are unchanged (lines 1243, 1245, 1246); the file's only changes
from 0.49.0 are the description of the local embedding runtime and `models.window_overlay_path`,
which is now accepted as any value and ignored (deprecated). Compiled: `dist/v2/server-cw6521wn.js`
and `dist/index-k6xvbj2e.js` line 5838 start `execute_threshold_percentage: union([` followed by the
three `number2().min(20).max(90, EXECUTE_THRESHOLD_CAP_MESSAGE)` calls (plain number, `default` key,
per-model catch-all), as shown by `opencode-magic-context-patches inspect --version 0.49.2` run on the
unpacked tarball in a sandboxed home: every snippet reads as in 0.49.0.

Running the 0.49.2 source schema (`MagicContextConfigSchema.safeParse`) on the live
`~/.config/cortexkit/magic-context.jsonc` gives exactly one issue: `execute_threshold_percentage`
"Too small: expected number to be >=20". Every other setting is accepted. The live configuration does
not set `models.window_overlay_path`, and no Fusiform overlay file exists under
`~/.local/share/cortexkit/`, so the removal of the window overlay changes nothing here.

## 4. Storage

The Magic Context database format stays 95 (`LATEST_SUPPORTED_VERSION = 95` in
`dist/v2/server-7vkj6zhb.js`, the highest migration `version: 95` in `dist/v2/server-6tcrjfw8.js`), as
the release notes of 0.49.1 and 0.49.2 state ("No migration. `context.db` stays at schema 95").

So the same three replacements make a configured 13 work as 13 on 0.49.2. The e2e test
`tests/e2e/lifecycle.test.ts` applies and undoes the patch on the fixture files and checks both
checksums. After updating to 0.49.2: `opencode-magic-context-patches apply`, restart OpenCode, then
`opencode-magic-context-patches effect` (expects `respected`).
